# 💡 Micro-Forum

A **micro-forum web app** built with the **MERN stack** (MongoDB, Express, React, Node.js).  
Users can:  
✅ Post new ideas  
✅ Upvote ideas  
✅ Comment on ideas  
✅ See the **most discussed ideas** highlighted  

---

## 🚀 Tech Stack

- **Frontend:** React, Axios, plain CSS / inline styles  
- **Backend:** Node.js, Express, MongoDB, Mongoose  
- **Database:** MongoDB Atlas / Local MongoDB  

---

## 📂 Project Structure

micro-forum/
│── micro-forum-frontend/ # React frontend
│── micro-forum-backend/ # Express + MongoDB backend


---

## ⚡ Features

- Post and share your ideas 💡  
- Upvote others’ ideas 👍  
- Add comments 💬  
- Auto-highlight **most discussed** idea with a badge ⭐  

---

## 🛠️ Setup Instructions

### 1️⃣ Clone the repository
```bash
git clone https://github.com/yogeshPatel9388/socialcomm


2️⃣ Setup Backend
cd micro-forum-backend
npm install
Create a .env file inside micro-forum-backend:

MONGO_URI=your_mongo_connection_string
PORT=5000
Run backend:

npm run dev


3️⃣ Setup Frontend
cd micro-forum-frontend
npm install
npm run dev

Frontend runs on 👉 http://localhost:5173

Backend runs on 👉 http://localhost:5000
